# Árkos

Árkos (Arkos Soluciones Informáticas S.A.C.S., RUC 20616338782) es una empresa peruana de software. Mejoramos los procesos de las empresas con software a medida y con la adopción de inteligencia artificial. Operamos desde Lima para todo el Perú.

Web: https://xn--rkos-4na.com (árkos.com)

## Cómo trabajamos

- Taller de adopción de tecnología: https://xn--rkos-4na.com/taller
- Diagnóstico de procesos: https://xn--rkos-4na.com/diagnostico
- Desarrollo a medida: ERP, CRM, PMS, SaaS, webs y apps, con cumplimiento SUNAT integrado cuando el proceso lo pide.
